# Tree Visualization - D3.js

A collapsible, interactive tree structure with zoom, pan, tooltips, and colorful depth highlighting.

## Features
- Left-to-right tree layout
- Node hover tooltips (Name, Parent, Children Count, Depth)
- Highlight paths to hovered node
- Zoom and Pan
- Leaf nodes styled differently
